# אליה שירותי מחשוב

אתר תדמית מקצועי עבור **אליה שירותי מחשוב** — Next.js, TypeScript, Tailwind CSS.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו [http://localhost:3000](http://localhost:3000).

## הגדרת פרטי קשר

עדכנו את `src/data/site.ts` או העתיקו `.env.example` ל-`.env.local`:

- `NEXT_PUBLIC_PHONE`
- `NEXT_PUBLIC_EMAIL`
- `NEXT_PUBLIC_WHATSAPP` (מספר בינלאומי ללא `+`, למשל `9725XXXXXXXX`)
- `NEXT_PUBLIC_SITE_URL`

## לוגו

קבצי הלוגו נמצאים ב-`public/logos/`:

- `logo-for-dark.jpg` — לשימוש על רקע כהה (Header / Hero / Footer)
- `logo-for-light.jpg` — לשימוש על רקע בהיר

## פריסה

```bash
npm run build
vercel
```

## ניהול הצעות מחיר

כניסה דרך `/login` וניהול דרך `/dashboard#quotes`. אפשר להתחבר ב־Google (החשבון המורשה הקיים) או בשם משתמש וסיסמה. בתוך **אבטחת חשבון** אפשר להגדיר פרטי כניסה חדשים; אימות דו־שלבי, אם מופעל, נדרש גם לפעולה זו וגם לשתי דרכי הכניסה.

- הצעות נשמרות ב־Firestore, באוסף `quotes`. המספור מוקצה בטרנזקציה דרך `system/quoteCounter`.
- טיוטות ניתנות לעריכה. הפעלת קישור ללקוח נועלת את התוכן. לשינוי הצעה שנשלחה יוצרים עותק חדש.
- קישורי לקוחות חתומים באמצעות `AUTH_SECRET`. טיוטות אינן נגישות בקישור ציבורי.
- אישור ודחייה שומרים את שם המשיב, המועד וגרסת ההצעה בטרנזקציה. תשובה חוזרת או אישור לאחר פקיעת התוקף נדחים.
- מחירים נשמרים באגורות, עיגול מתבצע לכל שורה ולאחר מכן להנחה ולמע״מ. שיעור המע״מ נקבע ידנית, וברירת המחדל היא 0%.
- שיתוף בוואטסאפ פותח הודעה להכנה; אין שליחה אוטומטית. ניתן להדפיס או לשמור PDF דרך הדפדפן ולייצא את הרשימה המסוננת ל־CSV.
- סימון תשלום הוא מעקב פנימי בלבד ואינו מפיק חשבונית או קבלה.
- נעשה שימוש בתשתית Firestore ובמשתני הסביבה הקיימים; אין צורך להוסיף שירות או סודות חדשים.

בדיקות: `npm test` ו־`npm run build`. הבדיקות משתמשות במסד בזיכרון ואינן ניגשות לנתוני הלקוחות.
